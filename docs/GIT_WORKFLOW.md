# Git・リモート運用

## 初回

1. Git未初期化なら初期化する。
2. 人が作成したリモートURLを提示してもらう。
3. URLを復唱し、確認後に `origin` へ登録する。
4. 接続を検証する。
5. 生成済みプロジェクト一式を日本語で初回コミットし、プッシュする。
6. プッシュできるまで実装へ進まない。

## 通常作業

- 作業前に直前の正常な状態がコミット・プッシュ済みか確認する。
- 人や別作業の未整理変更を無断でコミット、破棄、退避しない。
- 影響の大きい作業は日本語のIssueを作り、Issue番号を含むブランチで作業する。
- テスト後に日本語のPRを作る。
- PRは人がレビューし、人がマージする。
- Codexは明示的に依頼されない限りマージしない。

## 影響の大きい作業

- 複数の主要機能や画面にまたがる
- データ構造、認証、権限、決済、外部API、公開設定を変える
- データ消失、情報漏えい、停止の可能性がある
- 既存利用者の操作や保存データの互換性を変える
- 半日を超える、または複数タスクに分かれる
