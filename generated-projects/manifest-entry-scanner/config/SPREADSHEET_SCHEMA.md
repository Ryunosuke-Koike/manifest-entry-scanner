# スプレッドシート構造

## 設定方法

実験用スプレッドシートは人が作成する。IDはソースコードやGit管理ファイルへ書かず、Apps ScriptのScript Propertiesへ `SPREADSHEET_ID` として設定する。

## 読取履歴

| 列 | 見出し | 型・候補 | 必須 |
|---|---|---|---|
| A | レコードID | UUID | 必須 |
| B | 作業セッションID | UUID | 必須 |
| C | マニフェスト番号 | 11桁の数字 | 必須 |
| D | 票種 | A/B1/B2/C1/C2/D/E | 必須 |
| E | 登録日時 | 日本時間の日時 | 必須 |
| F | 担当者名 | 担当者一覧の有効な表示名 | 必須 |
| G | Googleアカウント | 同一ドメインのメールアドレス | 必須 |
| H | 読み取り方法 | 自動認識/手修正/手入力 | 必須 |
| I | OCR確信度 | 0〜100、手入力は空欄可 | 任意 |
| J | 処理時間ミリ秒 | 0以上の整数 | 必須 |
| K | 端末種別 | iPhone/Android/その他 | 必須 |
| L | ブラウザ種別 | Safari/Chrome/その他 | 必須 |
| M | 状態 | 有効/取消済み | 必須 |
| N | 取消日時 | 日本時間の日時 | 任意 |
| O | 取消実行者 | Googleアカウント | 任意 |

重複キーはC列とD列の組み合わせ。M列が「有効」の行だけを重複対象にする。

## 担当者一覧

| 列 | 見出し | 型・候補 | 必須 |
|---|---|---|---|
| A | 担当者ID | 一意な文字列 | 必須 |
| B | 表示名 | 日本語名 | 必須 |
| C | 状態 | 有効/無効 | 必須 |
| D | 表示順 | 0以上の整数 | 必須 |

## 作業イベント

| 列 | 見出し | 内容 |
|---|---|---|
| A | イベントID | UUID |
| B | 作業セッションID | UUID |
| C | 発生日時 | 日本時間の日時 |
| D | 担当者名 | 選択した表示名 |
| E | Googleアカウント | 同一ドメインのメールアドレス |
| F | 種別 | 開始/終了/自動認識/手修正/手入力/重複/取消/エラー |
| G | OCR確信度 | 0〜100、対象外は空欄 |
| H | 処理時間ミリ秒 | 0以上の整数 |
| I | 端末種別 | iPhone/Android/その他 |
| J | ブラウザ種別 | Safari/Chrome/その他 |
| K | エラーコード | 秘密情報を含まない短いコード |

マニフェスト番号全体や画像をエラー列へ記録しない。
