# マニフェスト登録スキャナー

スマートフォンでマニフェスト伝票の11桁番号と票種を端末内OCRで読み取り、指定したGoogleスプレッドシートへ登録できるか検証する社内向けWebアプリの実装プロジェクトです。

## 現在の状態

要件、段階的ゴール、技術構成、実装タスク、開発ルールを準備済みです。アプリ機能はまだ実装していません。

## コピー後の開始方法

1. `manifest-entry-scanner` ディレクトリ全体を、実装する場所へコピーします。
2. Codexでコピー先のディレクトリを開きます。
3. 次の指示を入力します。

```text
実装スタート
```

4. Codexへ、人が作成した実装用リモートリポジトリのURLを提示します。
5. リモート接続と初回プッシュ後、Issueと作業ブランチを作成してGoal 1から実装します。

## 実装前に必要なもの

- A・B1・B2・C1・C2・D・E票の見本画像（各10枚を目標）
- 実験用Googleスプレッドシート
- Google Apps Scriptを公開できる会社Google Workspaceアカウント
- iPhone/SafariとAndroid/Chromeの実機
- 人が作成したGitリモートリポジトリ
- 会社ルール上の登録履歴保存期間の確認

見本画像は秘密情報として扱い、Gitへコミットしません。撮影画像はアプリから外部送信・保存しない設計です。

## 主要ディレクトリ

- `src/`: Google Apps Script、画面、端末内OCRの実装先
- `config/`: スプレッドシート構造と設定方針
- `tests/`: 自動テストと実機確認
- `docs/`: 要件、技術構成、開発・テスト手順
- `plans/`: Goalと完了条件
- `tasks/`: 実装タスク
- `logs/`: 作業、失敗、改善の記録
- `reviews/`: 慎重派、実用派、統括レビュー

## 重要な運用

- 成果物はすべてこのプロジェクトルート内へ保存する
- 変更前に正常な基準点をコミット・プッシュする
- 影響の大きい作業はIssue、ブランチ、PRを使用する
- PRは人がレビューしてマージする
- コミット、Issue、PR、コードコメント、ログは原則日本語で記述する
