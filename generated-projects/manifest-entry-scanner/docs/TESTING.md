# テスト・確認計画

## 実装前の確認

- 7票種の見本画像が揃っている
- 見本画像がGit管理対象外である
- 実験用スプレッドシートが作成されている
- 「読取履歴」「担当者一覧」「作業イベント」の構造を管理者が確認している
- Google Apps Scriptを同一ドメイン向けに公開できる
- 会社ルール上の保存期間を確認する担当者が決まっている

## Goal 1: 成立性確認

### iPhone/Safari

1. 会社GoogleアカウントでWebアプリを開く
2. カメラ権限を許可する
3. 撮影枠へ番号と票種を合わせる
4. 7票種を各1枚以上撮影する
5. OCR候補、確信度、初回準備時間、2枚目以降の時間を記録する
6. Googleアカウントが空でないことを確認する
7. 実験用シートへ1件登録する

### Android/Chrome

同じ手順を実施し、端末・ブラウザ差を記録する。

### プライバシー確認

- ブラウザのネットワーク記録で、撮影画像、Blob、Data URLが外部送信されていない
- Apps Scriptとスプレッドシートのログに画像や番号全体が残っていない
- 撮影後にブラウザ内の画像参照が破棄される

## Goal 2: 70枚確認

- A・B1・B2・C1・C2・D・Eを各10枚
- 正解番号・正解票種と登録結果を人が照合する
- 誤った自動登録は0件でなければ不合格
- 自動認識正解率99%以上を目標として実測値を記録する
- 2枚目以降3秒以内を目標として、各処理時間を記録する
- 低確信度、撮り直し、手修正、完全手入力を確認する
- 同じ番号・同じ票種は登録されない
- 同じ番号・異なる票種は登録される
- 取消済みと同じ番号・票種は再登録できる
- 通信失敗時に次の伝票へ進まない
- 30分経過した未終了セッションを再開・終了できる
- 2〜3人が同時登録しても重複しない

## 自動テスト対象

- 11桁番号の入力検証
- 票種候補の入力検証
- OCR文字列の正規化
- 確信度による確認画面への分岐
- 重複キー生成
- 取消済みを除外した重複判定
- 自分の直前登録だけを取消できる条件
- 30分のセッション判定
- スプレッドシート行への変換
- 秘密情報を含まないエラー形式

自動テストの実行コマンドは、実装時に採用するテストランナーを固定した後でここへ追記する。未実装のコマンドは記載しない。

## 目標未達時

OCR、速度、カメラ、メール取得のいずれかが成立しない場合、次を記録して人の判断を待つ。

- 端末・ブラウザ
- 票種と撮影条件
- 実測値
- 原因の仮説
- 端末内でできる改善案
- 条件を変える案と、費用・プライバシーへの影響
