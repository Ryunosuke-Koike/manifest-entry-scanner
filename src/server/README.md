# Apps Scriptサーバー実装先

Goal 1から、次の処理を小さく実装します。

- Webアプリ画面の配信
- 同一Workspaceドメイン利用者の確認
- Script Propertiesからの記録先設定取得
- 担当者一覧取得
- 入力値の再検証
- LockService内での重複確認と登録
- 自分の直前登録の取消
- セッションと作業イベントの取得・記録

ブラウザから画像データを受け取る関数を作ってはいけません。ログへ画像、OAuthトークン、スプレッドシートID、マニフェスト番号全体を出力しません。

このディレクトリは初期ツリーだけで、サーバー機能は未実装です。
